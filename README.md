### 📖 About Me

This GitHub is my creative sandbox for studies and personal experiments. I enjoy building things from scratch, whether the result is a software tool or a physical circuit board.

- 🔍 **Philosophy:** I filter through many ideas, discarding the "dumb" ones until I find something worth building from the ground up.
- 🛠️ **Hardware:** When the software needs a physical home, it sometimes gets a schematic and a PCB of its own.
